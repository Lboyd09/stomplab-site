Privacy

This marketing site is static. It does not run a waitlist, does not have a form, and does not collect email, names, or which HX unit you own. Opening a page here does not create an account.

The live app

The product lives at stomplab.vercel.app. Auth is off. Featured songs work with no API key. If you paste a Gemini API key in Settings to research other tracks, that key stays in your browser on the app. It is not sent to this marketing site, and this site has no backend to store it.

What we do not do here

  • No mailing list signup on these pages.
  • No “we saved your email” message — because we don’t take one.
  • No sale of visitor data. There isn’t any to sell.

Hosting

If this site is deployed on Vercel, the host may log standard request data (IP, user agent, URL) for security and operations. That is their infrastructure, not a StompLab profile. See Vercel’s own privacy policy for how they handle logs.

Contact

Questions about the product: use the live app, or reach Liam Boyd, who is still improving StompLab. If a waitlist is ever added, it will only be for product updates, and this page will say so before any email is collected.
